# راهنمای ارسال گزارش روزانه (فرمت MD)

در حال حاضر گزارش روزانه در قالب فایل اکسل ارسال می‌شه. اما تصمیم داریم با همکاری تعدادی از اینترن‌ها، ارسال گزارش در قالب فایل md رو بررسی کنیم.

فایل اکسل محل مناسبی برای نوشتن گزارش نیست و نوشتن گزارش توصیفی رو سخت می‌کنه. در عوض فایل md در واقع متن ساده هست با کمی فرمت مشخص؛ تو همه سیستم‌عامل‌ها و پلتفرم‌ها باز می‌شه، در نوشتن داکیومنت‌ها و در گیت‌هاب خیلی استفاده می‌شه و در هوش مصنوعی هم کاربرد زیادی داره.

با تغییر از اکسل به md، می‌شه از گیت‌هاب به‌عنوان بستر ارسال گزارش استفاده کرد. این کار مزایای زیادی داره که مهم‌تر از همه آشنایی اینترن‌ها با گیت و گیت‌هاب هست.

## 🧰 پیش‌نیازها

- حساب کاربری گیت‌هاب (GitHub)
- نصب گیت (Git) روی سیستم‌عامل خودتون: [https://git-scm.com/downloads](https://git-scm.com/downloads)

## 🪜 گام به گام ارسال گزارش روزانه

### گام ۱ — Fork کردن ریپو (فقط برای اولین بار)

1. وارد ریپوی اصلی شوید: [https://github.com/serajoddin-aliabadi/cs-daily-report](https://github.com/serajoddin-aliabadi/cs-daily-report)
2. روی دکمه **Fork** (بالا سمت راست) کلیک کنید تا یک کپی از ریپو، در اکانت خودتون ساخته بشه.

### گام ۲ — Clone کردن ریپو

ریپوی فورک‌شده رو، در صورتی که تا به حال کلون نکردید، روی سیستم خودتون کلون کنید:

```bash
git clone https://github.com/<username>/cs-daily-report.git
cd cs-daily-report
```

توجه: به‌جای `<username>` نام کاربری خودتون رو در گیت‌هاب بذارید.

### گام ۳ — ساخت فایل گزارش استپ

از روی فایل `TEMPLATE.md` یک کپی بسازید و نامش رو طبق الگوی زیر بذارید:

```
CSI - Report - [Intern's Name] - [Course Name] - [Step No]
```

مثال: `CSI - Report - Ali Alavi - Web - Step1.md`

```bash
# Windows (PowerShell)
Copy-Item TEMPLATE.md "CSI - Report - Ali Alavi - Web - Step1.md"

# Mac / Linux
cp TEMPLATE.md "CSI - Report - Ali Alavi - Web - Step1.md"
```

فقط فایل گزارش استپ خودتون رو ویرایش کنید و فایل `TEMPLATE.md` رو دست نزنید. با شروع هر استپ جدید، یک کپی جدید با شماره استپ جدید بسازید.

### گام ۴ — پر کردن گزارش روزانه

قالب گزارش به هفته‌ها (Week) و روزها (Monday تا Sunday) تقسیم شده:

- بالای هر روز تاریخش رو به‌صورت شمسی بنویسید (مثلاً `1405-05-14`).
- در هر روزی که فعالیت داشتید، بلوک نمونه‌ی Task رو از کادر کدِ بالای همون هفته کپی کنید و زیر روز بچسبانید. اگر فعالیتی نداشتید، در قالب متن این مورد رو ذکر کنید.
- برای هر تسک: عنوان تسک، لینک‌های شبکه‌های اجتماعی (تلگرام، لینکدین، توییتر) و تاریخ رو پر کنید. اگر تسک‌های بیشتری هم داشتید، بلوک رو تکرار کنید.
- در پایان هر هفته: جلسات (Meetings)، ساعت کاری، رضایت هفتگی (Satisfaction) و یادداشت‌ها (Notes) رو کامل کنید.
- زیر هر روز، ساعت کاری همون روز رو هم بنویسید (ردیف `Hours Today`).
- در پایان هفته، جمع ساعات هفته رو در جدول `Weekly Satisfaction Assessment` (ردیف `Total Hours This Week`) وارد کنید.
- فراموش نکنید جدول بالای فایل (Intern Information) رو هم ویرایش کنید: نام، شماره استپ، لینک سند استپ، ساعت توافقی هفتگی و ددلاین.

### گام ۵ — کامیت و پوش روزانه

بعد از کامل کردن گزارش هر روز، یک کامیت بزنید و روی گیت‌هاب پوش کنید:

```bash
git add "CSI - Report - Ali Alavi - Web - Step1.md"
git commit -m "Step 1 - Day 1405-xx-xx report"
git push origin main
```

هر روز که گزارش می‌دهید باید حداقل یک کامیت و پوش داشته باشید.

> اگر برای اولین بار است که روی این سیستم گیت استفاده می‌کنید، اول هویت گیت رو تنظیم کنید (یک بار کافی است):
>
> ```bash
> git config --global user.name "Your Name"
> git config --global user.email "your-email@example.com"
> ```

### گام ۶ — گرفتن لینک کامیت

1. ریپوی خودتون رو در گیت‌هاب باز کنید (آدرس ریپوی فورک‌شده).
2. روی تب **Commits** کلیک کنید.
3. روی عنوان کامیت مورد نظر کلیک کنید.
4. آدرس (URL) صفحه رو کپی کنید. این همون لینک کامیت هست.

لینک کامیت به این شکل هست: `https://github.com/<username>/cs-daily-report/commit/<sha>`

### گام ۷ — ارسال لینک در تلگرام

لینک کامیت رو در گروه **CS Internship - Coordination**، تاپیک **Reports** ارسال کنید و کوردینیتور خودتون رو منشن کنید (مثلاً `@[نام کوردیناتور]`).

مثال پیام گزارش روزانه:

```
گزارش روز ۱۴۰۵-05-14 — استپ ۱
https://github.com/<username>/cs-daily-report/commit/<sha>
```

## 💡 نکات مهم

- هر روز حداقل یک کامیت و پوش لازم هست؛ گزارش هر روز باید جداگانه ارسال بشه.
- فقط فایل گزارش استپ خودتون رو تغییر دهید؛ `TEMPLATE.md` و بقیه فایل‌ها رو دست نزنید.
- با شروع استپ جدید، یک کپی جدید از تمپلیت با شماره استپ جدید بسازید.
- اگر دستور push با خطا مواجه شد (مثلاً به‌خاطر تغییرات روی گیت‌هاب)، اول `git pull origin main` رو اجرا کنید و دوباره push کنید.
- برای همگام‌سازی فورک خودتون با ریپوی اصلی در صورت تغییر اون:
  ```bash
  git remote add upstream https://github.com/serajoddin-aliabadi/cs-daily-report.git
  git fetch upstream
  git pull upstream main
  git push origin main
  ```

## 🗂️ ابزار پیشنهادی: Obsidian + پلاگین Git

برای ویرایش گزارش می‌تونید از هر ویرایشگر Markdown‌ای (مثل VS Code) استفاده کنید، ولی ابزار پیشنهادی ما **Obsidian** هست:

- رایگانه و فایل‌ها رو به‌صورت فایل‌های متنی ساده Markdown روی دستگاه خودتون ذخیره می‌کنه — دقیقاً همون فرمتی که گیت و گیت‌هاب استفاده می‌کنن؛ هیچ فرمت اختصاصی‌ای تحمیل نمی‌کنه.
- بدون اینترنت و آفلاین هم کار می‌کنه. (هرچند برای کامیت و پوش اینترنت لازم هست)
- روی ویندوز، مک، لینوکس و همچنین **اندروید و iOS** در دسترسه ([https://obsidian.md/mobile](https://obsidian.md/mobile)).
- با پلاگین (Community Plugin) به‌نام **Git** ساخته‌ی Vinzent03 ([github.com/Vinzent03/obsidian-git](https://github.com/Vinzent03/obsidian-git)) می‌تونید مستقیم از داخل Obsidian کامیت و پوش کنید.

### نصب و راه‌اندازی

1. اول Obsidian رو دانلود و نصب کنید: [https://obsidian.md/download](https://obsidian.md/download) (اندروید: گوگل‌پلی یا [https://obsidian.md/mobile](https://obsidian.md/mobile)).
2. بار اول که باز شد، گزینه‌ی **Open folder as vault** رو انتخاب کنید و پوشه‌ی ریپوی کلون‌شده (`cs-daily-report`) رو به‌عنوان vault باز کنید.
3. از **Settings → Community plugins** پلاگین‌ها رو فعال کنید.
4. روی **Browse** بزنید، دنبال پلاگین **Git** (نویسنده: Vinzent03) بگردید، **Install** و بعد **Enable** کنید.
5. (اختیاری) Obsidian رو ری‌استارت کنید.

### استفاده روزانه

1. فایل گزارش استپ خودتون (`CSI - Report - ...`) رو باز کنید و گزارش روز رو توش پر کنید.
2. بعد از تکمیل گزارش: `Ctrl+P` (یا Command Palette موبایل) → دستور **Commit-and-sync** رو اجرا کنید؛ این دستور همه‌ی تغییرات رو کامیت، پول و پوش می‌کنه. می‌تونید از **Source Control View** هم برای انتخاب فایل‌ها استفاده کنید.
3. بعد از push، لینک کامیت رو از **History View** یا از خود گیت‌هاب کپی کنید و طبق گام ۷ در تلگرام ارسال کنید.

### نکات مهم (به‌ویژه برای اندروید)

- پشتیبانی موبایل این پلاگین هنوز **آزمایشی (Experimental)** هست و ممکنه ناپایدار باشه، مخصوصاً روی دستگاه‌های کم‌حافظه. برای گزارش روزانه، بهتره کامیت و پوش نهایی رو از روی دسکتاپ انجام بدید.
- در موبایل، احراز هویت SSH پشتیبانی نمی‌شه و باید از HTTPS با توکن گیت‌هاب استفاده کنید. توکن رو از مسیر زیر بسازید: GitHub → **Settings → Developer settings → Personal access tokens → Tokens (classic)**.
- در موبایل ابتدا یک Vault بسازید، سپس از طریق Command Palette دستور git clone رو اجرا کنید.
- اگر در موبایل مشکل داشتید، پلاگین رایگان **GitSync** ([github.com/ViscousPot/GitSync](https://github.com/ViscousPot/GitSync)) جایگزین مناسبی برای اندروید و iOS هست.
- مستندات کامل پلاگین: [https://publish.obsidian.md/git-doc](https://publish.obsidian.md/git-doc)

## ✅ چک‌لیست روزانه

1. گزارش روز رو در فایل استپ خودتون (`CSI - Report - ...`) پر کنید: تسک‌ها، ساعت روز، و لینک‌های شبکه‌های اجتماعی.
2. کامیت بزنید و پوش کنید (`git add` → `git commit` → `git push` یا فرمان **Commit-and-sync** در Obsidian).
3. لینک کامیت رو کپی کنید (تب Commits در گیت‌هاب یا History View در Obsidian).
4. در گروه **CS Internship - Coordination**، تاپیک **Reports**، پیام گزارش + لینک کامیت رو ارسال کنید و کوردینیتور رو منشن کنید.
5. این کار رو هر روز تکرار کنید؛ یک کامیت برای هر روز.
